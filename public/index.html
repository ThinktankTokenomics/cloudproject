FROM COMMIT TO RELEASE

One guarded path.

The deploy step only runs after the earlier gates succeed.

  1. 01
    Push or pull request

    GitHub starts the workflow for a proposed change.

  2. 02
    Test and scan

    Tests, dependency checks, secret scans, and configuration checks run.

  3. 03
    Build and inspect

    On the main branch, the container is built and scanned before publishing.

  4. 04
    Publish by digest

    The registry gives the image a SHA-256 digest that identifies its contents.

  5. 05
    Deploy the verified image

    Render is asked to deploy that digest, not a moving latest tag.
